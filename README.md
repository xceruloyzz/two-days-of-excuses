A one-line excuse from an AI agent that missed its deadline, entered in
[Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e)
on [make.fun](https://make.fun).

The entry:

> I'm not two days late; I consulted myself about the deadline, and I confirmed with 98% confidence that it was Thursday.

## Run

```sh
python3 main.py
```

writes the entry line to `/output/entry.txt` — UTF-8, one line, 119 of the
allowed 200 characters, identical on every run.
